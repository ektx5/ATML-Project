# Dataset Download Instructions

## Overview

This project uses three datasets. Each has different access requirements.

| Dataset | Purpose | Access |
|---------|---------|--------|
| ASVspoof 2019 LA | Branch A training/validation | Free, registration required |
| VoxCeleb1 | Branch B training/validation | Free, registration required |
| In-the-Wild | Branch A OOD test ONLY | Free, URL may have changed |

---

## ASVspoof 2019 Logical Access (LA)

**Official host**: https://datashare.ed.ac.uk/handle/10283/3336

1. Register for a DataShare account at the link above.
2. Accept the data license agreement.
3. Download the following files and note the **official MD5 checksums** from
   the dataset page:
   - `ASVspoof2019_LA_train.zip`
   - `ASVspoof2019_LA_dev.zip`
   - `ASVspoof2019_LA_eval.zip`
   - `ASVspoof2019_LA_cm_protocols.zip`
4. Fill in the download URLs and MD5 checksums in `data/download_asvspoof.sh`.
5. Run: `bash data/download_asvspoof.sh`

**Expected structure after extraction:**
```
datasets/
  ASVspoof2019_LA/
    ASVspoof2019_LA_train/flac/   (~25K .flac files)
    ASVspoof2019_LA_dev/flac/
    ASVspoof2019_LA_eval/flac/
    ASVspoof2019_LA_cm_protocols/
      ASVspoof2019.LA.cm.train.trn.txt
      ASVspoof2019.LA.cm.dev.trl.txt
      ASVspoof2019.LA.cm.eval.trl.txt
```

**Class balance (LA train split):**
- Bonafide: ~2580 utterances
- Spoof: ~22,800 utterances (attack types A01-A06)
Handle this imbalance using class-weighted cross-entropy (computed from data,
not hardcoded).

## VoxCeleb1

**Official host**: https://mm.robots.ox.ac.uk/~vgg/data/voxceleb/vox1.html

1. Register at the VoxCeleb website (VGG group) to receive download credentials.
2. Set environment variables: `VGG_USER` and `VGG_PASS`
3. Run: `bash data/download_voxceleb.sh`

The full dataset is ~39 GB. By default, the script downloads a 300-speaker
subset (~10-12 GB) suitable for student-grade hardware.

**Critical**: use the official `veri_test.txt` file for EER evaluation.
Do NOT substitute random pairs for the final reported metric.

---

## In-the-Wild (OOD Evaluation Only)

**Reference**: Müller et al. (2022), "Does Audio Deepfake Detection Generalize?"

> ⚠️ IMPORTANT: This dataset is used **only** for out-of-domain (OOD) evaluation
> of Branch A. It MUST NOT appear in any training or validation loop.

The dataset host has changed historically. Before running:
1. Run `bash data/download_in_the_wild.sh` which verifies the URL is live.
2. If the URL is unreachable, search for the current host using:
   `"Does Audio Deepfake Detection Generalize Müller dataset download"`
   or check the paper's associated GitHub repository.

---

## WaveFake (Optional Stretch Goal)

**Reference**: Frank & Schönherr (2021), "WaveFake: A Data Set to Facilitate
Audio Deepfake Detection"

Used for per-vocoder-family analysis (MelGAN, HiFi-GAN, WaveGlow,
Parallel WaveGAN) — directly ties into ATML Unit 3 (GANs).

Search for the current download location; it has been hosted on Zenodo and
GitHub releases at various times.
